# 角向箍缩装置等离子体密度剖面重构AI算法研究
中国科学技术大学 本科毕业论文

## 项目简介
本项目针对传统等离子体密度剖面Abel反演方法存在的速度慢、噪声敏感、依赖理想柱对称等问题，
基于BP神经网络实现多道干涉仪信号到等离子体密度剖面的实时、高精度重构，
并与传统方法进行对比验证。

## 核心功能
- 多通道等离子体干涉仪信号预处理
- BP神经网络密度剖面反演模型
- 传统Abel反演对比实现
- 模型性能评估（KL散度、损失、推理速度）

##  运行环境
- Python 3.11
- numpy
- torch（支持 CUDA 加速）
- scipy
- matplotlib
- scikit-learn

## 文件结构
- train.py        模型训练主程序
- model.py        BPNN网络结构定义
- abel.py         Abel反演对比代码
- utils.py        数据预处理与工具函数
